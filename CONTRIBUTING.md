# Contributing to Chess-Electron

Thank you for your interest in contributing to Chess-Electron!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/chess-electron.git`
3. Install dependencies: `npm install`
4. Create a branch: `git checkout -b feature/your-feature-name`

## Development Guidelines

### Code Style

- Use 2 spaces for indentation
- Use single quotes for strings
- Follow existing code patterns in the project
- Keep functions small and focused

### Making Changes

1. Make your changes
2. Test the application: `npm start`
3. Build the application: `npm run dist`
4. Commit your changes with a clear message

### Commit Messages

- Use the present tense ("Add feature" not "Added feature")
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...")
- Limit the first line to 72 characters or less
- Reference issues and pull requests liberally

### Pull Requests

1. Update the README.md if needed
2. Test your changes thoroughly
3. Submit a pull request with a clear description
4. Be responsive to feedback

## Ideas for Contributions

- Add custom themes
- Implement notification support
- Add keyboard shortcuts
- Improve security settings
- Add more build targets
- Create installer packages for different platforms

## Questions?

Feel free to open an issue for any questions or discussions.
